# Website Template Advanced

Trang template giới thiệu dịch vụ thiết kế web, được xây dựng bằng HTML5 và CSS3 thuần.

## Cấu trúc dự án

```text
website-template-advanced/
├── index.html
├── css/
│   └── style.css
├── images/
│   ├── banner.svg
│   ├── service1.svg
│   ├── service2.svg
│   └── service3.svg
└── README.md
```

## Cách chạy

Mở `index.html` bằng trình duyệt. Không cần cài thư viện hay chạy máy chủ.

## Nội dung chính

- Header nền minh họa, lớp phủ và hiệu ứng blur nhẹ.
- Thanh điều hướng sticky ở đầu màn hình khi cuộn.
- Lưới 3 thẻ dịch vụ sử dụng CSS Grid và hiệu ứng hover.
- Bố cục Flexbox/Grid, kiểu chữ, khoảng cách và màu sắc nhất quán.
- Footer 2 cột với dấu chấm phân cấp nội dung.
- Responsive cho desktop, tablet và điện thoại.
- Hình minh họa SVG nằm trong dự án, không cần tải ảnh ngoài.

## Đưa lên GitHub

Tạo repository mới và tải toàn bộ thư mục lên, giữ nguyên đường dẫn `css/` và `images/`. Sau đó mở `index.html` để kiểm tra và nộp URL repository.
